# Product Steering — DeadLine BBS

## What this is
A resurrection, not a clone-for-clone's-sake. DeadLine BBS revives the *rituals* of a 1990s dial-up BBS — dialling in, the ANSI banner, numbered menus, posting to the board, browsing the file area, arguing with the SysOp, playing the door game — inside a modern browser.

## Audience
Hackathon judges and nostalgic callers. The demo must land in under 3 minutes: boot → menu → post a message → ask the SysOp something → play one door-game guess.

## Product rules
- **Fiction, clearly labelled.** Every person, post, file and phone number is fictional. Never solicit or store real personal data.
- **Zero friction.** No accounts, no backend, no API keys, no build step. Opening the page is the whole install.
- **Authentic but polished.** Period-accurate interaction (keyboard menus, monospace, ANSI colours) with 2026 usability (focus states, responsive layout, mouse/touch parity).
- **Every visual element earns its place.** Decoration must serve the BBS fiction (banner, scanlines, transfer logs) or usability. No filler graphics.
- **Sound-free.** The handshake is imagined, in text. Demos are often recorded in quiet rooms; silence is a feature.

## Tone
SysOp voice: dry, warm, slightly haunted. 1994 slang is seasoning, not the whole meal — a first-time caller must still understand every screen.
