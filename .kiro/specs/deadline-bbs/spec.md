# Spec — DeadLine BBS (deadline-bbs)

Kiro spec-driven development pack for the Kiroween 2026 Resurrection entry.
This spec is split in the standard Kiro layout:

- [requirements.md](requirements.md) — user stories and EARS-style acceptance criteria
- [design.md](design.md) — architecture, modules, design decisions, correctness notes
- [tasks.md](tasks.md) — implementation checklist (tasks 1–10 complete; 11–13 are Allen's submission steps)

**One-line summary:** Resurrect a 1990s dial-up BBS — boot handshake, ANSI banner, keyboard menus, message board, file library, rule-based AI SysOp, and a daily door game — as a zero-dependency, offline, static web app with only fictional content.

**Steering:** see `../../steering/product.md` and `../../steering/tech.md`.
**Hooks:** see `../../hooks/on-save-verify.kiro.hook`.
